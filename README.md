# Pic Skills

用于保存可复用的图片生成与改绘 skills。

## Skills

### baozi-watercolor-elements

为 baozi.space 生成统一的日式手绘水彩角色、物件、场景和网站插画元素，并支持基于参考图片改绘及定向迭代。

调用示例：

```text
Use $baozi-watercolor-elements to create a consistent watercolor illustration asset for baozi.space.
```

详细规则见 [`skills/baozi-watercolor-elements/SKILL.md`](skills/baozi-watercolor-elements/SKILL.md)。
